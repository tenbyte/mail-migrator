# Tenbyte Mail Migrator documentation

Tenbyte Mail Migrator is a local desktop application for mailbox migrations. IMAP is the supported default. CalDAV and CardDAV remain Alpha features and appear only after the user enables them for the current app session under Advanced settings.

The application transfers data directly between the configured accounts. It has no hosted migration service and does not upload mailbox contents to Tenbyte.

Migration tools can change account data. You are responsible for the settings and actions you choose, so keep an independent backup and test with non-critical data first. See [Data and security](Data-and-security.md) for details.
